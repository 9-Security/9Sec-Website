We test the file-verdict engine behind VERIS against known malware and known-good software. Detection rate = files judged malicious or suspicious.

False positives: 0 of 207 known-good files (Windows system files and common software, Ubuntu programs, system scripts) were judged malicious or suspicious. On a further 7,755 known-good scripts (Python, Git, Node.js and Windows system scripts), 1 was flagged as suspicious: an attack-simulation test script of our own.

"Content analysis only" approximates a never-seen sample: no reputation database is consulted. Each submitted file counts once; files unpacked from an archive count toward the archive. Scripts and archives remain the weak spots. Reputation lookups (MalwareBazaar, VirusTotal and others) catch more known samples, but our test samples come from MalwareBazaar itself, so we do not publish that number.
